## Research Note

Key insight: Decouple metering from billing and use event streaming to guarantee low‑latency, accurate usage records per tenant.  
- Implement a write‑ahead event log (e.g., Kafka) for every billable action; partition by tenant ID to ensure isolation and enable horizontal scaling without cross‑tenant contention.  
- Store aggregated usage in a time‑series DB (e.g., ClickHouse or InfluxDB) with pre‑computed roll‑ups (hourly, daily) to support real‑time dashboards and nightly invoicing jobs.  
- Design a rule‑engine microservice that consumes the event stream, applies per‑tenant pricing tiers, discounts, and caps, and writes idempotent charge records to a transactional store (PostgreSQL) for auditability.  
- Separate the billing UI from the core metering pipeline; expose a gRPC API for on‑demand usage queries, and use feature flags to roll out new pricing models without redeploying the metering layer.  

In practice, a SaaS HR platform serving 3,500 SMB tenants processed 12 million “pay‑run” events per month; using Kafka + ClickHouse reduced the average latency from event ingestion to billable record from 45 seconds to 3 seconds, cutting monthly invoice generation time from 4 hours to under 10 minutes. This improvement saved the company $120k in operational overhead annually.
