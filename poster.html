Problem Statement

India's 63 million small businesses run on WhatsApp groups, shared Excel files, and paper registers. Their data is scattered, unsecured, and disconnected across tools that don't talk to each other. Enterprise tools like Salesforce cost ₹40,000+/month and take months to set up — completely out of reach for small teams. There is no affordable, simple, all-in-one solution built for them.

Scope & Feasibility

Technically feasible using proven technologies — React.js frontend, Node.js + Express backend, PostgreSQL with tenant-scoped queries, and AWS for hosting. MVP covers 4 modules for Indian SMBs. Architecture supports future expansion: additional modules, third-party marketplace, and white-labeling.

Ideation — Key Objectives
1
Multi-Tenant Workspaces Every business gets a fully isolated workspace with its own subdomain (acme.platform.com). Data is scoped at the database level — no business can ever see another's data.
2
Plug-and-Play Module System Businesses activate only what they need: CRM, Inventory, HRMS, or HelpDesk. Unused modules stay off. Data is preserved when reactivated.
3
Role-Based Access Control (RBAC) Four roles: Owner → Admin → Manager → Staff. Enforced at the API middleware level on every request — not just hidden in the UI.
4
Unified Data Across Modules All modules share one database. A contact in CRM is the same record linked in HelpDesk. No more reconciling data across disconnected tools.
5
Affordable & Instant Setup Freemium model. No per-user pricing trap. A business can sign up and be fully operational in under 10 minutes.
Platform Modules
📊 CRM Leads, contacts, deals & sales pipeline for sales teams
📦 Inventory Products, stock levels, orders & supplier management
👥 HRMS Employees, attendance, leave management & payroll
🎫 HelpDesk Support tickets, agent assignment & resolution tracking
Role-Based Access Control
Owner Full control — billing, workspace deletion, all settings
Admin Manage members, activate modules, all operational access
Manager Approve leaves, assign tickets, manage within module
Staff Day-to-day work — create & update records, cannot delete
App Flow
01
Sign Up & Create Workspace Business owner registers → isolated workspace created with unique subdomain instantly.
02
Activate Modules Toggle on CRM, Inventory, HRMS, or HelpDesk from workspace settings. Only pay for what you use.
03
Invite Team & Assign Roles Send email invites to team members. Assign Owner / Admin / Manager / Staff roles per person.
04
Start Working Sidebar shows only active modules. Every user sees only what their role permits.
05
Full Audit Trail Every action is logged — who created, edited, or deleted what, and when. Data stays in the cloud.
Proposed Solution
✦
Platform, not a product — businesses assemble their own toolset by activating modules, like Shopify apps.
✦
True data isolation — every query is scoped with tenant_id at the database level, not just the UI.
✦
Middleware-enforced security — Auth → Tenant → RBAC → Module checks on every single API request.
✦
Freemium pricing — free for small teams, affordable paid plans. No ₹40,000/month Salesforce trap.
